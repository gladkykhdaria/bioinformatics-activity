0.The idea

A restriction enzyme is a pair of molecular scissors. It reads DNA, and whenever it finds its own short "password" sequence, it cuts there. Bacteria make these enzymes to chop up the DNA of viruses that attack them. They protect their own DNA by putting small chemical tags (methyl groups) on their own sites.

When I started, I noticed that this is almost exactly a text search followed by a split(). So I built it like that and kept a list of where the biology and the code meet:

1.The DNA

Why did I pick this sequence?It's Yersinia pestis plasmid pPCP1 (NCBI NC_005816), 9,609 bp. I first tried the 2,739 bp virus from lab 03, but there BamHI and HindIII cut only once, and the gel looked empty. This plasmid is longer, all 5 enzymes cut it, and it is a real circle, which turned out to change the maths (see section 6).

2.The five enzymes (from the board)

Red ▼ / ▲ = where each strand is cut. Yellow = the single-stranded "sticky" overhang left after the cut.

Why such strange names?The name is the bacterium it was found in. EcoRI = Escherichia coli, strain R, first enzyme. BamHI = Bacillus amyloliquefaciens H. HindIII = Haemophilus influenzae Rd, third one. TaqI = Thermus aquaticus (the same hot-spring bacterium that gave us Taq polymerase for PCR). HaeIII = Haemophilus aegyptius. So the name is basically a file path: genus / species / strain / number.

find_sites(dna, site, circular)step 2 · the enzyme scans the DNA
def find_sites(dna, site, circular):
    text = dna + dna[:len(site) - 1] if circular else dna
    hits, i = [], text.find(site)
    while i != -1 and i < len(dna):
        hits.append(i)
        i = text.find(site, i + 1)
    return hits

Look for the site, remember where it starts, keep looking from the next letter. For a circle I glue the first few letters to the end, so a site that crosses the "end" of the circle is not missed.

cut_positions(sites, offset, length)step 3 · where exactly it cuts
def cut_positions(sites, offset, length):
    return sorted({(s + offset) % length for s in sites})

The enzyme doesn't cut at the start of the site but a few letters inside it (EcoRI after the first G). So cut = site start + offset. The % length wraps it around for a circle.

fragments(cuts, length, circular)step 4 · measure the pieces
def fragments(cuts, length, circular):
    if not cuts:
        return [length]
    if circular:
        return [(cuts[(k + 1) % len(cuts)] - cuts[k]) % length or length
                for k in range(len(cuts))]
    edges = [0] + cuts + [length]
    return [b - a for a, b in zip(edges, edges[1:]) if b > a]

Each piece is the distance from one cut to the next. On a straight line I also add the two ends of the DNA. On a circle the last piece goes around the end back to the first cut, so n cuts give n pieces (not n + 1).

migration(length)step 5 · where each piece ends up on the gel
def migration(length):
    lo, hi = math.log10(GEL_MIN), math.log10(GEL_MAX)
    return 4 + 92 * (hi - math.log10(length)) / (hi - lo)

Same idea as lab 05: the distance a piece travels depends on log10 of its size. Small pieces run far, big ones stay near the wells.
