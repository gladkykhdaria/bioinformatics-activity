Transposon Cases Lab

A random DNA sequence with transposons placed in all three tricky ways: one after the other, one inside another, and two crossing each other. The program finds each one from its inverted repeats and reports where it starts, where it ends and how long it is.

0.The idea

A transposon is marked by an inverted repeat (IR) at each end: the right end is the left end read backwards on the other strand. In lab 06 my transposons were always nicely separated. This time the task is harder. Transposons can sit inside other transposons or overlap them, and the distance between the two IRs has a minimum of 10 bases but no maximum.

That broke two things in my old program. It deleted any result that overlapped another one, and it stopped looking after 150 bases. So I rewrote the search to keep every pair of inverted repeats it finds, and to describe how they relate to each other.

One after the other

[A>.....<A]   [B>.....<B]

A ends before B starts.

Nested

[A>.. [B>...<B] ..<A]

B is completely inside A. In real genomes this happens when a transposon jumps into another one.

Overlapping

[A>.. [B>.. <A] ..<B]

B starts inside A but ends after it. The two cross.

build_index(seq, k)step 1 · a dictionary of all short words
def build_index(seq, k):
    index = {}
    for j in range(len(seq) - k + 1):
        index.setdefault(seq[j:j + k], []).append(j)
    return index

Every 11-letter word in the sequence is stored with the positions where it appears. Later I can ask "where is this word?" and get the answer at once, without reading the whole sequence again.

detect(seq, min_ir, min_gap)step 2 · find pairs of inverted repeats
for i in range(len(seq) - min_ir + 1):
    for j in index.get(revcomp(seq[i:i + min_ir]), ()):
        if j - (i + min_ir) < min_gap:
            continue
        s, e, m = grow(seq, i, j + min_ir, min_gap)

For each word, I make its reverse complement (read it backwards and swap A↔T, C↔G) and look it up. If it appears at least 10 bases further on, the two words could be the two ends of a transposon. There is no upper limit, so a transposon can be as long as the whole sequence.

grow(seq, s, e, min_gap)step 3 · find the real edges
while s > 0 and e < n and seq[s - 1] == COMP[seq[e]]:
    s -= 1
    e += 1
m = 0
while (e - m - 1) - (s + m + 1) >= min_gap and seq[s + m] == COMP[seq[e - 1 - m]]:
    m += 1

The 11-letter match may only be part of the IR. So I move outwards while the letters still pair up (this finds the real start and end), then inwards to measure how long the IR is. Many small matches inside the same IR all grow into the same transposon, and I keep it only once.

relation(a, b)step 4 · nested, overlapping or separate?
if a.start < b.start and b.end < a.end:            return "contains"
if b.start < a.start and a.end < b.end:            return "inside"
if a.start < b.start <= a.end < b.end:             return "overlaps"
otherwise:                                          return None   # one after the other

Only the start and end of the two transposons are compared. This is the same logic you use to check whether two time intervals in a calendar overlap.
