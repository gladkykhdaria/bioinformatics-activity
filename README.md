## Bioinformatics Activities

This repository contains my lab activities from the bioinformatics course. Each folder contains Python(or any other prog.lang.) scripts and other files related to the lab tasks.

### Lab 01 – DNA Sequence Analysis
- Counts the four DNA bases: A, C, G, and T.
- Calculates the frequency of each base.
- Counts 2-letter and 3-letter combinations in a DNA sequence.
- Shows the results in charts.

### Lab 02 – DNA to Protein Translation
- Converts DNA sequences into mRNA.
- Reads codons and translates them into amino acids.
- Finds start and stop codons.
- Explores reading frames and protein changes caused by mutations.

### Lab 03 – Genome and Codon Analysis
- Analyzes genome sequences from FASTA files.
- Counts codons and calculates their frequencies.
- Shows the most common codons in a genome.
- Includes an HTML tool for exploring viral genomes and their genetic information.


Lab 04 – Genome Assembly

* Takes 20,000 random reads (100–150 nt) from a viral genome.
* Rebuilds the genome by finding overlaps between reads.
* Checks coverage and shows what happens when there are gaps.
* Compares the rebuilt genome with the original (100% match).
* Includes an HTML tool with charts for reads, coverage and contigs.

### Lab 05 – Gel Electrophoresis and DNA Repeats
- Takes 10 random DNA fragments (100–3000 bp) from an NCBI sequence and stores them in an array.
- Simulates how the fragments move on an electrophoresis gel based on their size.
- Finds repeats where a 3–5 base unit appears several times in a row (6–10 bases in total).
- Compares the number of repeats with shuffled random DNA.
- Includes an HTML tool with an animated gel and the repeats marked in the sequence.

### Lab 06 – Transposable Elements
- Builds an artificial DNA sequence (200–400 bases) with 3–4 transposons.
- Each transposon has inverted repeats at its ends and direct repeats around it.
- Detects the start and end of each transposon using only the sequence.
- Checks the result against an answer key (99.9% exact on 14,000 tests).
- Includes an HTML tool with a map, coloured sequence and accuracy test.

### Lab 07 – Restriction Enzymes
- Cuts a bacterial plasmid from NCBI with 5 restriction enzymes (EcoRI, BamHI, HindIII, TaqI, HaeIII).
- Counts the cuts for each enzyme and gives the cut positions and fragment lengths.
- Handles circular DNA, where n cuts give n fragments.
- Can cut with several enzymes at once and shows which enzyme made each cut.
- Simulates the electrophoresis gel for each enzyme, for any mix, and for all 5 together.
- Includes an HTML tool that shows every function step by step on the real data.
