## Bioinformatics Activities

This repository contains my lab activities from the bioinformatics course. Each folder contains Python(or any other prog.lang.) scripts and other files related to the lab tasks.

### Lab 01 – DNA Sequence Analysis
- Counts the four DNA bases: A, C, G, and T.
- Calculates the frequency of each base.
- Counts 2-letter and 3-letter combinations in a DNA sequence.
- Shows the results in charts.

### Lab 02 – DNA to Protein Translation
- Converts DNA sequences into mRNA.
- Reads codons and translates them into amino acids.
- Finds start and stop codons.
- Explores reading frames and protein changes caused by mutations.

### Lab 03 – Genome and Codon Analysis
- Analyzes genome sequences from FASTA files.
- Counts codons and calculates their frequencies.
- Shows the most common codons in a genome.
- Includes an HTML tool for exploring viral genomes and their genetic information.
