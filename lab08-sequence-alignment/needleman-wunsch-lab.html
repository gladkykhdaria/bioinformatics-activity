Needleman-Wunsch Lab

Aligning two DNA sequences from end to end (global alignment). The page fills the score matrix one cell at a time, follows the path back, and shows the alignment, so every step of the algorithm can be seen.

0.The idea

Two DNA sequences that come from the same ancestor slowly change: a letter gets replaced (a mismatch), or a letter is added or lost (a gap). Aligning means writing them one under the other so that the shared letters line up, and then counting how similar they are.

There are far too many ways to place the gaps to try them all. Needleman and Wunsch (1970) found a trick: the best alignment of the full sequences is built from the best alignments of their beginnings. So you fill a table with those small answers and reuse them. In computer science this is called dynamic programming.

4.How the program works, function by function

The same functions as in needleman_wunsch.py, with the real values for the sequences above.

init_matrix(n, m, gap)step 1 · first row and first column
for i in range(n + 1):
    M[i][0] = i * gap
for j in range(m + 1):
    M[0][j] = j * gap

Aligning the first i letters of S1 with nothing means i gaps, so the first column is 0, gap, 2·gap, … The same goes for the first row.

fill(s1, s2, match, mismatch, gap)step 2 · every other cell
diag = M[i - 1][j - 1] + score(s1[i - 1], s2[j - 1], match, mismatch)
up   = M[i - 1][j] + gap
left = M[i][j - 1] + gap
M[i][j] = max(diag, up, left)

There are only three ways to reach a cell. Diagonal: put the two letters together (match or mismatch). From above: S1's letter faces a gap. From the left: S2's letter faces a gap. Keep the best one. Each cell only needs its three neighbours, which are already filled.

traceback(s1, s2, M, …)step 3 · read the alignment back
while i > 0 or j > 0:
    if M[i][j] == M[i-1][j-1] + score(...):  take both letters, go ↖
    elif M[i][j] == M[i-1][j] + gap:         S1 letter + "-",  go ↑
    else:                                    "-" + S2 letter,  go ←

Start in the bottom-right corner (the final score) and ask: which neighbour did this value come from? Step there and write down the letters. Repeat until the top-left corner. The letters are collected backwards, so they are reversed at the end.
