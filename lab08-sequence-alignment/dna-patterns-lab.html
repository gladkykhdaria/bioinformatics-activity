DNA Patterns Lab

A 30-letter window slides along a DNA sequence. For every position it measures two things: how much C+G the window has, and how much it repeats itself. Each window becomes one point, and all the points together make a "pattern", a kind of fingerprint of the sequence.

0.The idea

A promoter is the stretch of DNA right before a gene, where the cell decides whether to read that gene. Promoters of different kinds of genes look different: some are full of C and G, some have a lot of A and T. Instead of reading the letters, this method turns a sequence into a picture, so different sequences can be compared at a glance.

information_content(seq)the formula from the board
def self_match(seq):
    n = len(seq)
    total = 0
    for u in range(1, n):
        same = sum(f(seq[i], seq[i + u]) for i in range(n - u))
        total += same / (n - u) * 100
    return total / (n - 1)

def information_content(seq):
    return 100 - self_match(seq)

I copy the sequence, shift the copy by u letters, and count how many letters line up with themselves (f = 1 if equal, 0 if not). I do this for every shift from 1 to n − 1 and average the percentages. A repetitive window like AAAA… matches itself almost everywhere, so its self-match is high and its information content (100 − self-match) is low.

pattern(seq, size) + center_of_weight(points)all windows, then their average
def pattern(seq, size):
    return [(i + 1, cg_content(w), information_content(w)) for i, w in sliding_windows(seq, size)]

def center_of_weight(points):
    n = len(points)
    return sum(p[1] for p in points) / n, sum(p[2] for p in points) / n
